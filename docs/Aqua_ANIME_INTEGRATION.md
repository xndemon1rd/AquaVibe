# Aqua Anime Integration

Added an Aqua-branded integration point for the search -> anime -> episode ->
stream-link architecture documented by TechShreyash/AniPlay. The upstream
AniPlay repository is MIT licensed and uses Pyrogram/Python; its README says
it is powered by TechZApi. The related AnimeDexLite project states that its
hosted APIs are inactive, so this build intentionally does not ship a
pretend-working endpoint.

Upstream: https://github.com/TechShreyash/AniPlay
