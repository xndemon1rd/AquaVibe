# 2026-10-01 — Gemini model update

- Text AI default updated from `gemini-2.5-flash` to `gemini-3.8-flash`.
- Gemini image default updated from `gemini-2.5-flash-image` to `gemini-3.1-flash-image` because Google lists the 2.5 image model for shutdown on October 2, 2026.
- Existing environment variables remain supported: `GEMINI_MODEL` and `GEMINI_IMAGE_MODEL`.
